On [Products](/products) you can export your products as a CSV file and import a CSV file back.

## The safest way

1. **Export first.** The exported file has exactly the columns an import expects. Open it in Excel or Google Sheets.
2. Edit the rows you want to change, or add new rows. Keep the column names as they are.
3. Save as CSV and choose **Import**.

## Check before anything changes

An import is shown to you first: how many products **will be added**, how many **will be updated**, and the rows **with problems**, with the reason for each. Nothing is saved until you confirm. Rows with problems are left out; fix them and import them again.

After you confirm, you see how many products and variants were added and updated.

## Good to know

- Your package's product limit applies to imports too.
- Pictures are added on each product's page, not in the file.
