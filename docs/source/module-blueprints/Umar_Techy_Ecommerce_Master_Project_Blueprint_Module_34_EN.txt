DOCUMENT PURPOSE
------------------------------------------------------------
This module defines the complete Help, Support, Knowledge Base,
Documentation, Onboarding, Troubleshooting, Developer Support,
Tenant Support, and Operational Assistance framework for the Umar
Techy Core Multi-Tenant E-Commerce SaaS.

The objective is to make the platform understandable, supportable,
maintainable, and usable by:

- Store owners
- Store administrators
- Store staff
- Customers
- Developers
- Integration partners
- Marketplace app developers
- Affiliate/reseller users
- Umar Techy support staff
- Umar Techy Super Admins
- Internal engineering and operations teams

Documentation is a product capability, not merely a collection
of static pages.

This module MUST provide contextual, version-aware, permission-aware,
tenant-aware, searchable, maintainable, and secure documentation
without exposing restricted information.

This module does not replace business logic, authorization, or
security controls defined in Modules 01–33.

DOCUMENT LANGUAGE
------------------------------------------------------------
All technical specifications in this module are intentionally
written in English.
